# Repository Labels

This repository uses a controlled set of labels to ensure consistent issue
classification and maintainability.

Only the labels listed below may be used.

Maintainers should not introduce additional labels unless the repository
governance policy is updated.

## Allowed Labels

| Label         | Purpose                                  |
|---------------|------------------------------------------|
| bug           | Software malfunction or defect           |
| support       | Usage or configuration help              |
| security      | Security vulnerability report            |
| enhancement   | Feature request or improvement           |
| documentation | Documentation issues                     |
| installation  | Installation or deployment problems      |
| compatibility | Platform or runtime compatibility issues |
| question      | General questions about usage            |

## Label Governance

Labels are automatically applied through issue templates whenever possible.

Issues using incorrect labels may be relabeled or closed by maintainers.

## Maximum Label Policy

The repository intentionally limits labels to this small set in order to:

- simplify issue triage
- prevent label proliferation
- maintain predictable issue categorization
